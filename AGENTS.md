# CompatLens Repository Instructions

Read `CLAUDE.md` before changing the repository.

Before type tracing, code authoring, or test work, read
`.claude/rules/type-standards.md`. Before touching tests, mocks, test setup, or
coverage, also read `.claude/rules/testing.md`.

`README.md` states what the tool does and where it stops; `docs/privacy.md`
states exactly what it reads, keeps and exports. Both are public promises, so
change them in the same commit as the behaviour they describe.
